# GraphEdu — уроки и визуальные модели

## Источник данных уроков

- Полный снимок девяти стандартных уроков и всех их заданий из последней пользовательской резервной копии хранится в `src/backupCourseSeed.ts`.
- При первой загрузке версии с каталогом `graph-edu-code-catalog-v4` стандартные уроки и задания записываются из этого файла в `localStorage`.
- Правки через редактор сохраняются в браузере. Чтобы перенести их в исходники, экспортируй JSON и передай его для следующего обновления.
- Дополнительные уроки с собственными ID не удаляются при миграции.

## Модели во вкладке «Граф»

Конструктор графов поддерживает переключение между:

- **Статичным графом** — схема без анимации.
- **BFS** — очередь FIFO, порядок посещения и просмотр шагов.
- **DFS** — стек рекурсивных вызовов, углубление и возврат.
- **Компоненты связности** — отдельный запуск обхода для каждой непосещённой компоненты.
- **Поиск циклов** — обход и подсветка проверенных рёбер.
- **Дейкстра** — релаксация рёбер и расстояния от стартовой вершины.
- **MST / Краскал** — сортировка рёбер по весу, выбор остовных рёбер и суммарный вес.
- **Беллман — Форд** — последовательные проходы релаксации, включая отрицательные веса.
- **Флойд — Уоршелл** — пошаговое улучшение расстояний через промежуточные вершины.

Можно менять стартовую вершину, перемещать/добавлять/удалять вершины и рёбра, задавать подписи и цвета. Для взвешенных алгоритмов веса рёбер редактируются отдельно. Переключатель ориентированности позволяет показывать направления и выбирать, считать ли рёбра односторонними.

## Модель сетки / Flood Fill

Новый блок **«Сетка / Flood Fill»** отображает клетки и стены. В режиме редактирования можно переключать клетки между стеной и свободной областью, а в режиме просмотра — пошагово видеть распространение заливки от стартовой клетки. Стандартные графические примеры урока Flood Fill автоматически преобразуются в сеточную модель при первичной загрузке.

## Навигация и запуск

В учебном режиме вопрос может требовать правильного ответа для перехода дальше. В режиме «Редактировать» можно свободно листать слайды.

Запуск в Windows PowerShell:

```powershell
npm.cmd install
npm.cmd run dev
```

Проверка TypeScript:

```powershell
node node_modules/typescript/bin/tsc -b
```

При первом запуске версии v4 флаги прохождения стандартных уроков сбрасываются, поскольку содержимое синхронизируется с последней резервной копией. После миграции новые правки из редактора не перезаписываются автоматически.

## Публикация сайта без аккаунтов

GraphEdu можно опубликовать как статический сайт: для базовой версии не нужен сервер приложения и не нужны аккаунты. Подойдут GitHub Pages, Cloudflare Pages или Netlify; команда сборки — `npm run build`, каталог публикации — `dist` (для GitHub Pages с адресом вида `username.github.io/repository/` нужно отдельно настроить `base` в `vite.config.ts`).

Прогресс сейчас хранится в `localStorage` браузера на устройстве ученика. Это удобно для анонимного использования, но данные не синхронизируются между браузерами и устройствами и могут пропасть при очистке данных сайта. Рекомендуется оставить экспорт/импорт резервной копии. Код ученических решений отправляется на внешний Judge0 для компиляции и проверки; перед публичным запуском следует проверить доступность сервиса, лимиты и условия обработки данных. Если когда-нибудь понадобится общий рейтинг или перенос прогресса между устройствами, потребуется отдельный сервер/API и добровольная идентификация — для текущего сценария это не требуется.

## Отчёты ученика

На панели задач есть кнопка «Скопировать отчёт урока». Отчёт включает статусы и баллы по задачам, попытки, активное время, ответы, код решения и результаты тестов. Время учитывается, пока вкладка открыта и видима. Ученик может вставить скопированный текст в файл или отправить преподавателю.

### Отчёт по всем урокам
Кнопка «Скопировать все логи» в верхней панели формирует сводный текстовый отчёт по всем курсам на основе localStorage. Отчёт актуален на момент нажатия и содержит статусы, попытки, длительность, ответы, код и результаты тестов.
